SYSTEM OVERVIEW

The Binary Times is a hands-free content publishing pipeline that transforms tech news aggregation into a fully automated, AI-curated Facebook publication. From RSS ingestion to published post, the system operates 24/7 without human intervention.

The workflow leverages a multi-agent architecture where one AI agent acts as Chief Editor (selecting unique, high-impact stories), while a second agent handles content generation (writing viral captions and generating image text). All state is persisted to Google Sheets, creating a continuously learning system that never republishes content.

WORKFLOW ARCHITECTURE

[ n8n Workflow Canvas Screenshot ]

Visual workflow showing all connected nodes

01 — RSS Ingestion & Data Structuring

n8n RSS nodes poll multiple tech publication feeds (The Verge, TechCrunch, Ars Technica, Engadget). A custom JavaScript execution node parses aggregated JSON, filters domains, and limits story intake to prevent API rate limiting while maintaining high-quality input.

02 — Agent 1: The Story Selector

LangChain agent connected to Google Sheets tool (historical database) with Buffer Window Memory. Cross-references incoming news against the last 10 published posts to guarantee 100% unique content, ranking stories based on "Technical Impact" score. Structured JSON output ensures consistent parsing.

03 — Agent 2: The Content Writer

Gemini 2.5 Pro agent scrapes original article metadata and generates viral, 3-part Facebook caption (Hook, Deep Dive, Engagement Question) plus a punchy 5-word image overlay text. Structured output parsers ensure the LLM responds in perfect JSON schema, preventing pipeline crashes.

04 — Dynamic Image Compositing

n8n editImage nodes build branded graphics programmatically: downloads logo from private Google Drive, resizes and composites onto generated background, renders AI-generated 5-word punchline using custom font files (Impact.ttf, Times_New_Roman.ttf) with dynamic sizing and line wrapping calculations.

05 — Publishing & State Management

Facebook Graph API v23.0 receives multipart form payload with finalized image buffer and AI-generated caption. Published headline, URL, and timestamp are logged back to Google Sheets, continuously updating the Story Selector Agent's memory for future deduplication.
