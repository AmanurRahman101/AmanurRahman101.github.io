// DESKTOP APPLICATION

DEGUNK

Windows System Memory Optimizer for Gaming

A Windows desktop application designed to free up system memory (RAM) by pausing non-essential background applications, primarily to optimize performance for gaming. Built with C#, .NET 6.0, and WPF featuring a modern Fluent Design UI.

// SYSTEM ARCHITECTURE

Core Components

GamingModeManager.cs

The "brain" of the application. Handles process discovery, filtering, termination, and resumption. Uses aggressive process tree killing with fallback to graceful closures. Persists state to config.json in AppData/Roaming/DeGunk.

SystemRamHelper.cs

Native Windows API interop using P/Invoke to call GlobalMemoryStatusEx from kernel32.dll for real-time, highly accurate physical memory statistics.

ProcessIconHelper.cs

Extracts native high-quality ICO files directly from running executables using Icon.ExtractAssociatedIcon for an authentic, polished UI experience.

UiBackdropHelper.cs

Handles transparent "Mica" and "Acrylic" window backdrops for that modern Windows 11 Fluent Design aesthetic using WPF-UI library integration.

// KEY FEATURES

What Makes It Special

Smart Process Filtering

  • Automatically whitelists critical Windows processes (explorer, svchost, csrss)
  • Protects developer tools (VS Code, Visual Studio, Cursor)
  • Groups related background services (NVIDIA overlay, etc.)
  • Prevents accidental OS crashes from over-aggressive termination

Live RAM Monitoring

  • Real-time memory usage with color-coded progress bars
  • "Before" and "After" comparison showing exact RAM freed
  • Continuous updates via native Windows API calls
  • Visual feedback with green/yellow/red thresholds

State Persistence

  • Saves stopped applications to config.json
  • Stores executable paths and working directories
  • Survives application restarts
  • One-click resume restores entire previous session

Modern Fluent UI

  • Mica/Acrylic transparent window backdrops
  • Rounded glass-like cards with subtle animations
  • Terminal-style activity log for transparency
  • Native application icons for visual recognition

Windows API Integration

DeGunk relies on P/Invoke to communicate directly with the Windows API for features not natively exposed in C#:

// SystemRamHelper.cs - Native memory status
[DllImport("kernel32.dll")]
static extern bool GlobalMemoryStatusEx(
  ref MEMORYSTATUSEX lpBuffer);
// Process termination with full tree kill
var psi = new ProcessStartInfo("taskkill")
{
  Arguments = $"/T /F /IM {processName}",
  CreateNoWindow = true,
  UseShellExecute = false
};
